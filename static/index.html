3 Prompt rewrites

Ultra rewrites the instructions and picks examples from the tuning split; it only ever sees tuning rows. Each candidate is scored on the tuning rows it did not use as examples and on the validation rows. The candidate with the best validation score is the only one scored on the held-out split, so the gap between the three scores shows how much the rewrite overfit.
